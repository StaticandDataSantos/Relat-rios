# Portfólio de Estatística e Ciência de Dados

Este repositório reúne projetos acadêmicos e práticos desenvolvidos ao longo da minha formação em Estatística e Ciência de Dados.

Os projetos têm como objetivo demonstrar conhecimentos em análise estatística, tratamento e exploração de dados, visualização, programação e comunicação de resultados.

## Projetos

### 01. Análise de Indicadores Demográficos de Pedra Azul (MG)

Relatório de análise demográfica desenvolvido a partir de dados públicos do IBGE/SIDRA e DATASUS.

O estudo aborda a estrutura etária da população, nascidos vivos, Taxa Específica de Fecundidade (TEF) e Taxa de Fecundidade Total (TFT), comparando o município de Pedra Azul com Minas Gerais e o Brasil.

### 02. Análise estatística com R

Projeto desenvolvido utilizando R Markdown para análise de um banco de dados.

### 03. Dashboard em Power BI

Projeto de análise e visualização de dados desenvolvido no Power BI, com foco na construção de indicadores e dashboards para apresentação dos resultados.

### 04. Análise de dados com Python

Projeto de análise de banco de dados utilizando Python, explorando técnicas de manipulação, tratamento e análise de dados.
